# Classes

All classes start with hl- so they never clash with Tailwind / Bootstrap.


Display / Direction

hl-flex · hl-inline-flex

hl-flex-row · hl-flex-col

hl-flex-wrap

Grow / Shrink

hl-flex-1 (fill remaining space)

hl-shrink-0 (never shrink)

Align items

hl-items-start · hl-items-center

hl-items-end · hl-items-stretch

Justify content

hl-justify-start · hl-justify-center

hl-justify-end · hl-justify-between

hl-justify-around

Gap (works with grid too)

hl-gap-0 = 0 · hl-gap-1 = 4px · hl-gap-2 = 8px · hl-gap-3 = 12px

hl-gap-4 = 16px · hl-gap-5 = 20px · hl-gap-6 = 24px
